Instructions
  1. Enter your Instagram credentials to login.
  2. Select whether you want to message a user (DM) or a group chat.
  3. Enter the target username or group ID.
  4. Type your messages in the text area (one per line) or upload a text file with messages.
  5. Optionally, add a prefix to be added before each message.
  6. Set the delay between messages (in seconds).
  7. Click "Start Sending Messages" to begin the process.
Tips
  • Use longer delays (10+ seconds) to avoid Instagram rate limits
  • Check your messages page to see sending progress
  • Keep message content organic to reduce risk of being flagged
  • For group chats, you'll need the numeric group ID
